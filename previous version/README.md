# Previous Version: Python + SQLite

This folder is a fully runnable copy of the old Python and SQLite version of the habit tracker.

## Run

```powershell
python app.py
```

or:

```powershell
.\run.ps1
```

The website opens at:

```text
http://127.0.0.1:8000
```

Progress is stored locally in this folder as `habits.db`.
